# 🕵️ 神探星途 · 深圳小学四年级智慧探案学院 (PWA)

专为**深圳小学四年级**（英语：**沪教牛津深圳版 4A/4B**；数学：**北师大版 4上/4下**）打造的零惩罚、侦探寻宝风互动学习应用。

## 核心设计理念

1. **专治“粗心、不认真审题”——放大镜扫线索**
   - 英语题先用放大镜点亮人称、时间词、照妖镜（`doesn't`）和问号，再作答；还有「抓语法小偷」改错关卡。
   - 数学题先圈出“往返”“还剩”“单位不同”“买 4 送 1”等高频陷阱词，点中即获即时口诀与额外星星。
2. **专克“数学逻辑弱、看不懂题”——可视化图解 + 难题切块**
   - 内置 5 种动态交互图解：**线段图 / 路程条**、**魔法方程天平**、**乘法分配律积木面积图**、**等腰三角形角度图**、**小数点对齐格子本**。
   - 把吓人的应用题拆成 2~3 个超轻松小步，每一步都能收获成就感。
3. **专治“畏难心理、害怕失败”——零惩罚鼓励系统**
   - 绝无红叉、扣分、扣血；答错只有温柔音效与阿探的暖心提示。
   - 3 级「免费求助锦囊」不扣星，坚持破案就能盖上 `CASE CLOSED` 红章并赢取星星给柴犬伙伴「阿探」换装。
4. **精准诊断 + AI 苏格拉底伴学**
   - 自动区分 **🔍 粗心型失误** 与 **🧩 概念/逻辑卡壳**，错题化身为「在逃嫌疑人」待复仇抓捕。
   - 内置离线本地引导模式；家长在右上角齿轮（解锁口令 `7×8=56`）填入 Gemini API Key 后，即可开启**拍题识图引导**与**按薄弱项 AI 定制新关卡**。

## 启动与在 iPad / 手机上使用

```bash
npm install
npm run dev
```

启动后终端会显示 `Local` 和 `Network`（如 `http://192.168.x.x:5173`）地址：
- **电脑端**：直接打开 `http://localhost:5173`。
- **iPad / 手机端（同一 Wi-Fi）**：用 Safari 打开终端显示的 `Network` 地址 → 点击底部分享按钮 → **「添加到主屏幕」**，即可像原生 App 一样全屏运行！
